# Meteo Montagna

PWA per scialpinismo e freeride: in un'unica schermata previsioni di neve in quota, radar e bollettini valanghe dei posti dove vai.

## Stato

In progettazione. Il codice dell'app arriverà con le prossime pull request.

## Pubblicazione

L'app sarà pubblicata con GitHub Pages su https://vizz00.github.io/meteo-montagna/
